# 트러스트웨이 홈페이지

`https://www.trustway.co.kr` 사이트의 소스입니다. `main` 브랜치에 푸시하면 GitHub Pages가 자동으로 배포합니다.

## 처음 시작하기 (관리자)

1. GitHub 계정으로 이 저장소 초대(협업자)를 수락합니다.
2. 컴퓨터에 저장소를 복제합니다: `git clone https://github.com/dataloop-billy/trustway-website`
3. 그 폴더에서 Claude Code를 실행합니다. `CLAUDE.md` 를 자동으로 읽고 작업 규칙을 따릅니다.
4. 예: "채용 섹션의 문구를 ○○로 바꾸고 배포해줘" 라고 요청합니다.

수정 후에는 `bash check.sh` 점검을 통과해야 푸시할 수 있고, 푸시 1~2분 뒤 사이트에 반영됩니다.
자세한 규칙과 주의사항은 `CLAUDE.md` 를 보세요.
